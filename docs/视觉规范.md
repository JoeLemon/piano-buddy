## 0. 设计定位

一句话：**深夜琴房的舞台感**——深墨绿铺满全局（像音乐厅的丝绒幕布），白色练习面板像聚光灯下的谱架，金色只负责高光。

- 全局背景为深墨绿，叠加低透明度五线谱音符暗纹（本风格标志性元素）；
- 内容一律落在**暖白卡片 / 面板**上（如参考图的「练习面板」弹窗），与深绿底形成强对比；
- 金色承担：进度、当前音、选中态、高亮 CTA、表盘描边，用量 **< 10%**；
- 整体拒绝：荧光绿、俗金渐变、发光。精致感来自**深绿与白的层次 + 金色点缀的比例**，不来自装饰堆砌。

| 错误（弹错 / 危险） | `#C0725C` | `#B96A55` | 弹错音、删除类 | `--pb-danger` / `--pb-pitch-mark` |
| 迟到（未跟上） | `#7E93A6` | `#6E7F92` | 迟到的音标记 | `--pb-late-mark` |

> 乐谱区始终位于暖白卡内（五线谱必须浅底高对比），标记色只按「暖白卡内」列取值。
> 标记用色原则：错误与警告用**颜色 + 形状双重编码**（颜色 + 下划线 / 圆点 / 星号）。

### 1.4 音符暗纹（标志性背景元素）

全局背景叠加五线谱与音符暗纹，营造琴房氛围：

```css
--pb-bg: #132F28;
--pb-bg-pattern: url("data:image/svg+xml,...五线谱+四分音符...");
/* 建议实现：body::before 固定定位铺满，opacity 约 0.04~0.05，mix-blend-mode: screen */
```

- 暗纹透明度 **3%–5%**，颜色为米白 / 亮金，绝不影响文字可读性；
- 移动端小屏可只保留音符点纹或整体弱化（避免噪点）；
- 键盘区、导航栏可不叠暗纹（或叠更深的 `--pb-bg-deep`）。

### 1.5 使用比例与红线

- 金色占比 < 10%，只出现在：进度、徽章、当前音、选中态、表盘描边、高亮 CTA；
- 大面积只允许「舞台深绿 + 暖白面板」两级，金色永远是小面积高光；
- 深绿底上的正文不用纯黑、也不用低饱和绿做文字（对比不足）；
- 香槟金（v1.0）与墨绿浅底方案整体废弃，统一收敛到本版金绿体系。

## 2. 字体与排版

### 2.1 字体家族（跨平台）

核心思路不变：**标题衬线（典雅感），正文无衬线（可读性）**；深色舞台下标题可渲染为米白或亮金。

| 层级 | 品牌首选 | Web / 跨平台实际使用（低改造成本） | 用途 |
|---|---|---|---|
| 显示 / 标题 | Playfair Display（拉丁）+ Noto Serif SC（中文） | 沿用现有 `Source Serif 4` + `Songti SC` + `Noto Serif SC` 回退链 | 曲名、页面大标题、模块标题、**App 名（Piano Buddy 衬线 logo）** |
| 正文 / UI | SF Pro Text / Noto Sans SC | 沿用现有 `IBM Plex Sans` + `PingFang SC` + `Microsoft YaHei` 回退链 | 正文、按钮、说明、标签 |
| 数字 / BPM / 拍号 | Inter（tabular-nums） | 正文族 + `font-variant-numeric: tabular-nums` | 节拍、速度、计时表盘数字 |
| 乐谱音符 | Bravura（SMuFL 标准） | 谱面渲染专用 | 五线谱、音符、升降号 |

> Web 端沿用现有字体栈，避免新增加载成本；移动端品牌视觉引入 Playfair Display。

### 2.2 字号系统

基准沿用：`clamp(14px, 0.45vw + 13.4px, 17.5px)` 根字号自适应；语义层级：

| 层级 | 设计稿（px 基准） | Web（rem 建议） | 字重 | 用法 |
|---|---|---|---|---|
| H1 页面 / 曲名大标题 | 28 | `clamp(1.35rem, 1.1rem + 1.2vw, 1.75rem)`（沿用） | 600 | 页面主标题、曲目名 |
| H2 模块标题 | 20 | `clamp(1.1rem, 1rem + 0.5vw, 1.3rem)`（沿用） | 600 | 练习模块、统计、小节标题 |
| H3 卡片标题 | 17 | `1rem`（沿用） | 600 | 卡片、子模块 |
| Body 正文 | 15 | `0.9375rem` | 400 | 说明、教程、正文 |
| Caption 备注 | 12 | `0.8125rem` | 400 | 标签、时间、小字备注 |

### 2.3 文字规则

1. 衬线字体**只给标题**，正文一律无衬线；
2. 深绿底上的标题用米白 `#F2EEE2`，可少量用亮金 `#DFC98E` 提亮（如当前选中项）；暖白卡内标题用 `#3A3A35`；
3. 行高：正文 1.5，标题 1.2；标题字距轻微加宽 `0.01em~0.02em`；
4. 数字一律 `tabular-nums`（计时表盘 / BPM 不跳动）；
5. 禁止滥用斜体，仅曲目标题可轻斜。

## 3. 形状：圆角 / 阴影 / 间距

### 3.1 圆角（统一曲率，杜绝 6px 与 999px 混用）

| 令牌（新值） | 值 | 用途 |
|---|---|---|
| `--pb-radius-sm` | `6px` | 标签、小徽章、乐谱容器 |
| `--pb-radius` | `12px` | 按钮、输入框、小卡片、chip |
| `--pb-radius-lg` | `16px` | 大卡片、**练习面板弹窗**、自评题卡 |
| `--pb-radius-pill` | `999px` | 分段控件、进度条、圆点、表盘 |

### 3.2 阴影（暖白面板浮于深绿舞台的层次感）

```css
/* 浅色卡片在深绿底上的投影：深色、柔和、稍扩散 */
--pb-shadow: 0 1px 0 rgb(0 0 0 / 16%), 0 12px 32px rgb(0 0 0 / 28%);
--pb-shadow-1: 0 1px 2px rgb(0 0 0 / 20%);
--pb-shadow-2: 0 18px 44px rgb(0 0 0 / 36%);
```

- 白色面板必须带投影才会从深绿底上「浮起来」（参考图面板的边缘层次）；
- 面板之间的嵌套（面板内次级块）改用底色分区，不再加阴影。

### 3.3 间距（8px 栅格，与现有 `--pb-space-*` 兼容）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`。

| 场景 | 值 |
|---|---|
| 卡片内边距 | 16px |
| 模块间距 | 24px |
| 页面左右安全边距 | 移动端 16px / 桌面沿用 `--pb-max-width: 64rem` 居中 |

## 4. 组件规范（高频组件外观）

> 组件结构与现有 `tokens.css` 三层体系一致。以下只改观感，不动 DOM 与逻辑。

### 4.1 主按钮（高亮 CTA，参考图「跟随练习」）

- **暖白卡内主 CTA**：金色填充 `#C9A45C` + 深绿文字 `#132F28`，圆角 12px，hover 转亮金 `#DFC98E`；
- **深绿底上的主 CTA**：亮金填充 + 深绿文字，或墨绿填充 + 米白文字（二选一，页面内保持一致）；
- 次要描边按钮：深绿底上用 `rgb(242 238 226 / 28%)` 描边 + 米白文字；暖白卡内用 `#1D4438` 描边 + 墨绿文字；
- 禁用：`opacity 0.5` + `not-allowed`（沿用）。

### 4.2 左侧导航栏（参考图：曲目库 / 练习计划 / 技巧训练 / 演奏记录）

- 背景：舞台深绿（或 `--pb-bg-deep`），竖向排列；
- 未选中：图标 + 文字 `--pb-muted`（灰绿），无底；
- 选中态：左侧 2px **亮金竖条** + 文字 `#F2EEE2` 加粗，图标可转亮金 `#DFC98E`，整项叠加 `rgb(201 164 92 / 10%)` 底色；
- 图标：2px 线性线框（沿用 §5），未选中米白 70%、选中亮金。

### 4.3 分段控件 `.segments` / 进度条 / 状态点

| 组件 | 深绿底上 | 暖白卡内 |
|---|---|---|
| `.segments` 容器 | `rgb(242 238 226 / 8%)` 底 + 细描边 | `#EFEAE0` 底 + `#DCD5C7` 描边 |
| 选中项 | 金浅底 `rgb(201 164 92 / 16%)` + 亮金文字 | 白底 + `--pb-shadow-1` + 墨绿文字 600 |
| 进度条 | 轨道 `rgb(242 238 226 / 18%)`，填充 `#C9A45C` | 轨道 `#DCD5C7`，填充 `#C9A45C` |
| `.dot` | 按 §1.3 功能色（深底列） | 按 §1.3 功能色（暖白列） |

### 4.4 乐谱容器（核心组件，始终在暖白面板内）

- 背景 **纯白 `#FFFFFF`**（暖白面板内再细分一层，保证五线谱对比度）或直接以面板 `#FBFAF5` 承载；
- 圆角 8px，细边框 `#DCD5C7`；
- 音符 / 五线 `#1A1A1A`；当前音标记 `#C9A45C`（金色 + 加粗描边，参考图金风格）；正确 / 错误 / 迟到按 §1.3 暖白列；
- 谱面右上角可放小节进度 chip（金底墨绿字）。

### 4.5 钢琴键盘组件（参考图：深绿底上的白键键盘）

- 白键 `#F2EEE2`（米白，非纯白）；黑键 `#1D4438`（品牌墨绿）；键缝 `rgb(15 38 32 / 35%)` 极细线；
- 按下激活：白键填 `#C9A45C`、黑键填 `#DFC98E`；
- 音名标注（C / D / E / F / G）：白键上深灰绿 `#4A5A52` 小字，黑键上亮金小字；
- 扁平化，不做高光浮雕，键帽轻微圆角；键盘区背景 `--pb-bg-deep`。

### 4.6 练习面板弹窗（参考图中央白色弹窗）

- 暖白 `#FBFAF5`、圆角 16px、`--pb-shadow-2` 投影（深绿底上浮起）；
- 标题栏：衬线标题 + 金色细分割线；
- 面板内组件：计时表盘（金色圆环 + 米白刻度 + tabular-nums 数字）、数据折线图（金色线条 + 米白/灰绿网格）、练习列表；
- 底部主 CTA 贴左（「跟随练习」金色填充），右上角关闭。

### 4.7 标签 / 滑块 / 卡片

| 组件 | 规范 |
|---|---|
| `.tag` | 深绿底上：金浅底 `rgb(201 164 92 / 16%)` + 亮金文字；暖白卡内：金浅底 + 墨绿文字，6px 圆角 |
| 滑块 `input[type=range]` | 沿用细轨道结构；轨道 `--pb-border-soft`，圆点 `#C9A45C`（金色），拖动态亮金 |
| `.surface` 卡片 | 暖白 `#FBFAF5`、圆角 16px、`--pb-shadow`；**全局背景不再是卡片色** |
| 次级块 `.subsurface` | 面板内 `#EFEAE0` 底，无边框（沿用） |

## 5. 图标与配图

1. 图标风格：**线性线框**，2px 描边，端点圆角；
2. 图标颜色：深绿底上默认米白（70% 不透明度），选中 / 高亮亮金 `#DFC98E`；暖白卡内默认 `#1D4438`，激活金 `#C9A45C`；
3. 装饰元素：五线谱音符暗纹（全局背景，§1.4）、金色细线卷草纹（仅限面板标题分隔、空状态插画）；
4. 插图：低饱和、低对比的古典简约素描风（钢琴 / 琴房 / 乐谱），以米白 / 金色线条为主，适配深色环境；
5. 禁止：写实油画、华丽雕花堆砌、鎏金贴片、荧光色。

## 7. 动效

| 令牌 | 值（沿用现有） | 说明 |
|---|---|---|
| `--pb-dur` | `160ms` | 统一时长 |
| `--pb-ease` | `cubic-bezier(0.2, 0, 0.2, 1)` | 克制、线性入出 |

- 面板弹出：160ms 淡入 + 轻微上移（4px），不缩放不旋转；
- 键盘按下：激活色即时变化；
- 当前音跟随：160ms 淡入，不闪烁；
- 尊重 `prefers-reduced-motion`（现有已实现）。

- 深绿底上正文 `#F2EEE2` on `#132F28` 对比度 ≈ 11:1 ✅；次要文字 `#A6B5AC` on `#132F28` ≈ 5.6:1 ✅；
- 暖白卡内正文 `#3A3A35` on `#FBFAF5` ≈ 11:1 ✅；次要 `#6F6B60` ≈ 5.4:1 ✅；
- 金色**不单独承载信息**：必须与文字 / 图标 / 形状组合（金色文字只用于大号标题或选中态，且同时有形状变化）；
- 焦点态：`outline: 2px solid #DFC98E`（亮金，深色环境可见），暖白卡内用墨绿 `#1D4438`；
- 乐谱标记错误 / 警告使用颜色 + 形状双重编码；
- 音符暗纹必须极低透明度，不得影响文字可读性（小屏弱化或隐藏）。

## 9. 禁止清单（守住典雅感）

- ❌ 荧光绿、高饱和草绿（与舞台深绿冲突）；
- ❌ 俗金渐变、发光、鎏金、珠光特效；
- ❌ 大面积金色（占比 > 10% 即滑向"土豪风"）；
- ❌ 正文用衬线字体 / 标题用无衬线；
- ❌ 深绿底上使用低饱和绿文字（看不清）；
- ❌ 全局背景用纯黑替代舞台深绿（纯黑只允许乐谱内）；
- ❌ 白色面板不加投影直接贴深绿底（失去浮起层次）；
- ❌ 装饰花纹铺满屏幕、暗纹透明度超过 5%；
- ❌ 乐谱音符花里胡哨配色（只允许 §1.3 四种状态色）；
- ❌ 圆角混用（6px 与 999px 并存属历史遗留，一律按 §3.1 收敛）。

## 12. 设计考量与取舍（落地前值得知道）

1. **深绿舞台 + 白面板**：参考图的结构是「环境色 = 品牌色，内容色 = 白色」。好处是品牌感极强、一眼辨识；代价是**全局环境偏暗**，需要保证面板占比足够大、文字对比达标，长时间练习不压抑——面板是主战场，深绿是氛围。
2. **金色是双刃剑**：参考图的金色克制而高级。一旦超过点缀比例或做成渐变金，立即滑向"土豪 / 酒店风"。落地时把 `--pb-accent-2*` 的使用处列入 review 清单。
3. **与竞品差异化**：Simply Piano / Skoove / Yousician 均为浅色或科技蓝紫。深墨绿 + 金是明确的音乐厅 / 古典差异化路线，与「典雅钢琴练习」定位一致。
4. **暗纹的成本与收益**：音符暗纹是风格标志，但 SVG data-uri 过大或透明度不当会造成噪点 / 性能负担。建议：单色极简 SVG、只铺 body 背景一层、小屏弱化。
5. **令牌语义迁移的坑**：`--pb-ink` 语义从「深色文字」变为「深底上的米白文字」，卡片内文字必须走新令牌，否则改完一片浅底米字——这是本次迁移最大的回归风险点。
6. **字体取舍**：Web 保留现有字体栈是最低改造成本；若要更强的典雅感，再评估 Playfair Display + 字体子集化。
