# Piano Buddy

识谱与视奏训练 App，面向**自学成人钢琴初学者**。

> MVP 版本：先识谱，再视奏。某一档视奏只使用已经过关的音和节奏。本地运行，算法生成原创练习。

## 功能范围（MVP）

- 难度自评只决定从哪一课开始，不能直接进入视奏
- 与 L1~L6 视奏共用词汇表的识谱课：可以看键盘，弹错可重来
- 识谱过关后才解锁同档视奏
- 本地算法生成原创视奏短句（消耗式题库，一条最多 2 遍）
- 智能指法提示（视奏可开关，识谱始终显示）
- MIDI 键盘实时弹奏识别
- 节拍器、乐谱预览、分句练习
- 练习复盘，错题本（只收视奏）
- PDF 导出视奏谱

## 非功能范围（MVP）

- 无社区、无在线曲库、无麦克风拾音识别
- 不包含流行歌曲完整弹奏功能、不做考级模块
- 不做系统乐理课程。识谱只教符号对应的键和拍子
- 识谱不使用「一条最多 2 遍」；视奏不取消这条规则

## 技术选型

可选：

- Flutter 跨平台（iOS + Android）
- Web（Vue + VexFlow）原型

本地计算；Web MIDI / Flutter MIDI；本地 SQLite / IndexedDB 存储。

## 开发目标

验证自学成人是否愿意先认熟一小套音和节奏，再用带指法提示的视奏短句继续练。
