# 键盘输入与音区导航

学练页的输入有两条路：**屏幕琴键（鼠标 / 触摸 / 电脑键盘）** 和 **MIDI 硬件**。
MIDI 那条路沿用 `src/midi/access.ts`；这份文档记录屏幕琴键这一条的设计约定。

这套东西是为了对齐迁移前的练习器 `piano-projects/00-SightReading_3.0`
（`src/components/FullPianoKeyboard.tsx` 与 `docs/superpowers/specs/2026-06-05-piano-zone-thumbnail-design.md`），
交互语义按那份设计实现，配色换成本项目的金 × 深绿。

## 1. 为什么分上下两块

全尺寸钢琴是 A0–C8 共 88 键，按真实比例排开约 1560px，屏幕放不下。所以：

- **上部缩略图**：整台琴压成一条迷你琴，叠 7 个音区框，负责「我现在在哪一段」；
- **下部全尺寸琴键**：横向滚动，负责「按哪个键」。

两者共用一套槽位坐标（白键下标 slot），因此缩略图滑块与琴键滚动是一一对应的。

## 2. 7 个音区

| 编号（数字键） | 音域 | 白键数 | D 键弹出的 C |
| --- | --- | --- | --- |
| 1 | A0–B1 | 9 | C1 |
| 2 | C2–B2 | 7 | C2 |
| 3 | C3–B3 | 7 | C3 |
| 4 | C4–B4 | 7 | C4（默认） |
| 5 | C5–B5 | 7 | C5 |
| 6 | C6–B6 | 7 | C6 |
| 7 | C7–C8 | 8 | C7 |

首尾两段不是整八度（钢琴最低音是 A0、最高音是 C8），缩略图按白键数等比分配宽度，
所以这两段看起来窄一些，和真琴一致。迁移前的练习器用的是同一套切法。

模型在 `src/keyboard/layout.ts`：`ZONES`、`whiteKeys()`、`blackKeys()`、`zoneForMidi()`、
`zoneCMidi()`、`canZonePlay()`、`zoneScrollTarget()`、`cMarks()`。
**注意**：乐谱渲染仍用 `notation/renderScore.whiteKeyMidis()` 的 C3–C5 局部键，两者不要混用。

## 3. 电脑键盘映射

```
Q  W  E  R  T  Y  U  I  O  P        ← 黑键行
  A  S  D  F  G  H  J  K  L  ;  '    ← 白键行
```

规则只有一条：**D 键永远是当前音区的 C**；其余按琴键的物理位置对应——
R 在 D 的右上角，所以 R 是 C#；T 是 D#；U/I/O 是 F#/G#/A#。
E、Y、P 落在「没有黑键的豁口」上（B–C、E–F、B–C），像真钢琴那两个缺口一样不发声；
Q 是最低黑键左边，同样不发声。

- 白键行从 A 起算：`A`=A（上一个八度）、`S`=B、`D`=C、`F`=D … `;`=C（下一个八度）、`'`=D。
- 单个音区的可弹范围是 `[C-3, C+14]`，超出 88 键的键（如音区 7 的 `'`）自动失效。
- 实现：`src/midi/keyboard.ts` 的 `ROW_OFFSETS`（相对 C 的半音偏移）、`keyToMidi`、
  `keyCapFor`、`keyCapsFor`、`codeForMidi`。

### 音区切换

- `Digit1`–`Digit7` 切换 `activeZone`；切换时会先给按住的键补 `off`，避免旧音区的音一直响。
- 文本输入框里按数字不会切音区（`isTypingTarget`）。
- 练习高亮换到当前音区够不着的音时，`followMidi()` 自动切到包住它的音区；
  够得着就不动，免得打断用户手动选的音区。视奏页不显示琴键图，也在换谱/换手时调一次
  `followMidi()`，否则左手 C3 会被弹成 C4。

## 4. 三种输入如何汇合

所有来源都产出同一个 `MidiNote`，用 `source` 区分：`"midi" | "keyboard" | "screen"`。

- 屏幕琴键 `emit("note", …)`，视图的 `onNote` 直接复用；
- 视图对 `source === "screen"` 不检查 `midiConnected`（屏幕上看得见就点得动），
  硬件 MIDI 与电脑键盘仍要求连接/模拟键盘模式。

## 5. 缩略图与音区的交互（对齐迁移前的练习器）

三条状态，缺一不可：

1. **视窗滑块**：毛玻璃框，按 `scrollLeft / 总宽` 定位、按 `clientWidth / 总宽` 定宽。
   静止时只留一层很淡的底（`opacity` ~0.7），滚动或切换音区时提亮一档，700ms 空闲后回落。
2. **音区框**：浅色圆角矩形，常驻显示音域名（`C4–B4`）。激活音区（电脑键盘当前映射到的那段）
   用金底金边常驻标示；**刚点过**的音区另行闪 900ms 更强的选区框。
3. **手动/程序滚动的区别**：点音区是程序滚动，选区框保留；用户自己滑键盘时选区框立刻消失。
   判定用时间戳（150ms 内的滚动算程序触发），因为平滑滚动会连发多个 `scroll` 事件。

其余约定：

- **点音区只定位**：立即把该音区滚到视窗中间（`zoneScrollTarget`），不发声、不作答。
- 缩略图整体在静止时压暗（`opacity .82`），`hover` / `focus-within` / 滑动中提亮，
  不让它抢走琴键的注意力。
- hover/focus 的金色描边只在 `@media (hover: hover) and (pointer: fine)` 下给，避免触屏粘住 hover。
- C 标注（`C1`–`C8`）两处都有：缩略图迷你琴下方一行，全尺寸琴键下方一条标注带；
  中央 C 单独加重，作为课程原点。

## 6. 弹奏与输入细节

- 点按 / 触摸即发声：`src/audio/keyTone.ts`（按压起音、松开收音、无 AudioContext 时静默降级）。
- 按住拖动滑过琴键 = 滑奏（`pointerenter` 换音），**只在鼠标上启用**：触摸的横划要留给
  「平移键盘」、竖划留给「滚页面」。
- 琴键 `touch-action: manipulation`：轻点即发声，横划让浏览器平移键盘，竖划滚页面。
- 滚轮在琴键区上下滚 = 横向滚动。
- 打开时对准正在弹的那个音（没有目标音才对当前音区）；高亮音换到视野外时自动滚过去。
  窄屏上这一条决定了左手五指位会不会被裁掉一半。
- 标注：`keyLabels` 控制键帽标注（模拟键盘打开时自动打开，也可以单独关掉）。
