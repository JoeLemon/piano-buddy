# Piano Buddy

识谱与视奏训练 App，面向**自学成人钢琴初学者**。

> MVP 版本：先识谱，再视奏。某一档视奏只使用已经过关的音和节奏。本地运行，算法生成原创练习。

## 指法引擎（pianoplayer 移植）

指法计算接入 [pianoplayer](https://github.com/marcomusy/pianoplayer)（MIT）的算法，
完整移植在 `src/domain/fingering.ts`（对应上游 `pianoplayer/hand.py`）：

- **算法**：9 音滑动窗口 + 深度 3–9 的带回剪枝搜索，最小化「加权手指移动速度」
  （手指力量权重 + 黑键偏好）；剪枝规则覆盖逆行穿指、拇指上黑键、同和弦指序与
  伸展上限；支持和弦（每个音一个指法）与锚点（谱上已有指法原样保留）。
- **接入方式**：`annotateScore(score)` 在乐谱组装后执行。默认 `fill-gaps` 模式——
  识谱课的固定五位手位指法作为锚点保留，求解器只补越出手位的音与和弦音，
  L1/L2 现有行为完全不变；`auto` 模式则整段交给求解器。
- **保真度**：`test/fixtures/pianoplayer_harness.py` 对上游求解器实跑生成基准，
  `test/fingering.test.ts` 逐条比对（音阶、半音阶、双手和弦、锚点等 15 个场景）。
- 与上游的两处适配：键盘坐标用单调映射（对齐上游乐谱路径 `keypos()`）；
  时间单位用拍（默认 bpm=60 时数值与上游一致）。

## 界面结构（信息架构）

全站只有四个分区，顶栏不再堆功能按钮：

```
今日   ← 首页：一张「下一步」主卡 + 学习路径 + 换个练法
课程   ← 识谱课 L1/L2、L3 预备课、视奏、过关测试、复盘
曲库   ← 选曲、试听、看缺哪些技能
乐理   ← 符号 / 音程 / 和弦 / 临时升降 / 和弦进行 / 旋律听辨
```

- **今日只推一件事**：`src/domain/nextStep.ts` 的 `nextAction(profile)` 按
  自评 → L1 → L2 → 视奏 的顺序算出唯一建议动作，首页只渲染这一张主卡。
  判断逻辑不在视图里，改路径只改这一处。
- **分区导航**：`今日 / 课程 / 曲库 / 乐理` 常驻在顶栏；进入识谱、视奏、
  过关测试、复盘时自动收起（沉浸模式），避免练习中误点走开。
- **顶栏只留三样**：设备状态（一键连接）、节拍器开关与速度、设置。
  模拟键盘、主题、连接诊断、键盘映射说明都收进右侧设置抽屉，随时按 Esc 关闭。
- **标题只有一处**：顶栏左侧只显示分区名，页面标题由页面自己给；
  曲库、复盘、自评这些自带 `h1` 的页面不再重复出第二行标题。
- **设计令牌**：`src/ui/tokens.css` 定义颜色、间距、圆角、层级、动效，以及
  `.surface`（卡片）、`.lead/.note`（排版）、`.segments`（分段控件）、`.dot`（状态点）
  和统一的 `input[type=range]` 样式。视图的 scoped 样式只写本页独有的布局。
- **宽度与谱面**：页面画布 64rem（顶栏、导航、内容同宽）。谱面按容器宽度等比
  压缩小节宽度（下限 0.72，更窄时保留横向滚动），并裁掉上下多余留白，
  三到四小节不再出现横向滚动条。

## 功能范围（MVP）

- 难度自评只决定从哪一课开始，不能直接进入视奏
- 与 L1~L6 视奏共用词汇表的识谱课：可以看键盘，弹错可重来
- 识谱课两档：L1 单手五个白键（C 位），L2 八分音符、双手、F/G 五五指与一次平移
- 识谱过关后才解锁同档视奏；L2 过关后视奏升级为双手大谱表
- 本地算法生成原创视奏短句（消耗式题库，一条最多 2 遍）
- 智能指法提示（视奏可开关，识谱始终显示）
- MIDI 键盘实时弹奏识别
- 模拟键盘输入：没有 MIDI 键盘时用电脑键盘弹奏（设置抽屉 → 输入方式）
- 节拍器（可调速与开关）、乐谱进度条、随弹奏自动滚动与三色标注
- 练习复盘，错题本（只收视奏）
- PDF 导出视奏谱
- 乐理练习入口：符号、音程、和弦、临时升降、和弦进行、旋律听辨（内容改编自 00-SightReading_3.0）
- L3 预备课：5 节（三和弦 / 临时升降 / 双音音程 / 和弦连接 / 综合小测），完成记录写进本地档案；技能账本只记 `learning`，不等于过关

## 模拟键盘输入（无 MIDI 键盘时）

顶栏右上「设置」→「输入方式」→ 把「模拟键盘」打开，即可用电脑键盘代替 MIDI 键盘弹奏。
开启后顶栏设备状态会显示「模拟键盘」，屏幕下方琴键会标注对应键位，练习流程
（识谱 / 视奏 / 过关测试）与真实 MIDI 完全一致。

```
黑键   S D   G H J        2 3   5 6 7
白键   Z X C V B N M      Q W E R T Y U I
       C D E F G A B      C D E F G A B C
       低音区 (C3–B3)      高音区 (C4–C5)
```

键盘监听只在模拟键盘开关打开时生效；输入框内打字、按住 Ctrl/Cmd 时不会触发音符。

## 识谱课：L1 与 L2

L1 用单手五个白键把符号和拍子认熟；L2 在同一套键盘上继续加料，每一步都只加一样东西：

- **L2-1 八分音符**：一拍两个八分音，还是那五个白键。
- **L2-2 双手交替**：右手一小节、左手一小节，不同时弹。
- **L2-3 双手同拍**：两手节奏相同，或一只手拉长音、另一只手走四分/八分。
- **L2-4 F 五指 / L2-5 G 五指**：各带一个调号（F 一个降号、G 一个升号），
  先右手找对 8 个、再左手找对 8 个；谱上的黑键直接在模拟键盘/琴键图上标出。
- **L2-6 五指平移**：一条短句里从 C 位挪到 D 位一次，两条短句后进 L2 过关测试。
- **L2 过关测试**：一条新的 4 小节双手谱，含八分音符，调在 C/F/G 里抽一个，60 BPM；
  音高错不超过 2 个、明显的节奏中断不超过 1 次；同一档连续 3 次不过降 8 BPM（最低 44）。

找键课用计数推进：弹错不扣分也不回退，只记弹对的次数，所以卡住时重弹同一个键就好。

## L3 预备课

L3 目前没有完整的识谱/视奏课，只有一节 5 课的预备入口，用来补曲库里最常见的四个门槛：

- **三和弦**：大三、小三、增、减，先认两个三度的叠法。
- **临时升降**：升号、降号、还原号，以及「临时记号只管本小节」。
- **双音音程**：二度到八度里拼写清楚的 12 个常见音程。
- **和弦连接**：I–IV–I、I–V–I 与大小调级数。
- **综合小测**：把上面四类混在一起，至少答对 6/7 才算完成。

完成状态写在 `Profile.l3PrepCompleted`，技能账本只写 `learning`。曲库页的缺技能清单仍要求 `passed`，所以上完预备课不会直接解锁曲目；这样保留「课内学习」和「过关测试」的边界。

## 视奏的读谱辅助

视奏页把「准备—演奏—复盘」三段做得更看得见：

- **听一遍**：准备阶段点「听一遍」会从头播这条，同时进度条往前走、谱面上正在响的那个音用强调色跟随，页内自动滚到它的位置；播完自动收回，不留下标记。
- **小节进度**：进度条按小节画出刻度，右侧用「第 n/4 小节」标出当前位置。
- **准备倒计时**：25 秒准备有可视化进度条，并将这条还剩几遍（消耗式题库最多 2 遍）写在页面上。
- **复盘总览**：复盘页先给一行「共 4 小节 · 错音 n 处 · 节奏偏差 n 处」，再是谱面标记。不使用百分制。
- **双手视奏**：L2 过关后视奏默认双手大谱表，进度条与「第 n/4 小节」按两手同一拍点线算；「听一遍」会把两手一起播一遍。

## 非功能范围（MVP）

- 无社区、无在线曲库、无麦克风拾音识别
- 不包含流行歌曲完整弹奏功能、不做考级模块
- 不做完整 L3–L6 系统课程。L3 预备课只补曲库门槛；L4+ 仍只有技能规则和曲目，没有配套微课
- 识谱不使用「一条最多 2 遍」；视奏不取消这条规则

## 开发目标

验证自学成人是否愿意先认熟一小套音和节奏，再用带指法提示的视奏短句继续练。
