# Piano Buddy

识谱与视奏训练 App，面向**自学成人钢琴初学者**。

> MVP 版本：先识谱，再视奏。某一档视奏只使用已经过关的音和节奏。本地运行，算法生成原创练习。

---

## 指法引擎（pianoplayer 移植）

指法计算接入 [pianoplayer](https://github.com/marcomusy/pianoplayer)（MIT）的算法，
完整移植在 `src/domain/fingering.ts`（对应上游 `pianoplayer/hand.py`）：

- **算法**：9 音滑动窗口 + 深度 3–9 的带回剪枝搜索，最小化「加权手指移动速度」
  （手指力量权重 + 黑键偏好）；剪枝规则覆盖逆行穿指、拇指上黑键、同和弦指序与
  伸展上限；支持和弦（每个音一个指法）与锚点（谱上已有指法原样保留）。
- **接入方式**：`annotateScore(score)` 在乐谱组装后执行。默认 `fill-gaps` 模式——
  识谱课的固定五位手位指法作为锚点保留，求解器只补越出手位的音与和弦音，
  L1/L2 现有行为完全不变；`auto` 模式则整段交给求解器。
- **保真度**：`test/fixtures/pianoplayer_harness.py` 对上游求解器实跑生成基准，
  `test/fingering.test.ts` 逐条比对（音阶、半音阶、双手和弦、锚点等 15 个场景）。
- 与上游的两处适配：键盘坐标用单调映射（对齐上游乐谱路径 `keypos()`）；
  时间单位用拍（默认 bpm=60 时数值与上游一致）。

## 界面结构（信息架构）

全站是五个分区，顶栏不再堆功能按钮：

```
今日   ← 首页：一张「下一步」主卡 + 今日练习状态 + 学习路径 + 换个练法
学习   ← 三条课程线：识谱主线 L1/L2、L3 和弦课、L3 乐理预备课
练习   ← 自由乐理练习、10 组专项题组、视奏、错题本
曲库   ← 选曲、试听、分段跟弹、看缺哪些技能并直达对应微课
我的   ← 识谱/和弦/乐理进度、练习记录、设置入口
```

- **今日只推一件事**：`src/domain/nextStep.ts` 的 `nextAction(profile)` 按
  自评 → L1 → L2 → L3 → 日常视奏的顺序算出唯一建议动作，首页只渲染这一张
  主卡；曲库从 L2 起随时可进，L3 过关后学习路径的当前段就是曲库。
  判断逻辑不在视图里，改路径只改这一处。
- **今日完成态**：主卡下方固定显示「今天已练过 / 今天还没开始」、今天的条数与
  时长、连续练习天数，数据来自 `src/domain/practiceLog.ts`。
- **分区导航**：`今日 / 学习 / 练习 / 曲库 / 我的` 常驻在顶栏；进入识谱、视奏、
  过关测试、复盘时自动收起（沉浸模式），避免练习中误点走开。
- **顶栏只留三样**：设备状态（一键连接）、节拍器开关与速度、设置。
  模拟键盘、主题、连接诊断、键盘映射说明都收进右侧设置抽屉，随时按 Esc 关闭。
- **标题只有一处**：顶栏左侧只显示分区名，页面标题由页面自己给；
  曲库、复盘、自评这些自带 `h1` 的页面不再重复出第二行标题。
- **设计令牌**：`src/ui/tokens.css` 定义颜色、间距、圆角、层级、动效，以及
  `.surface`（卡片）、`.lead/.note`（排版）、`.segments`（分段控件）、`.dot`（状态点）
  和统一的 `input[type=range]` 样式。视图的 scoped 样式只写本页独有的布局。
- **宽度与谱面**：页面画布 64rem（顶栏、导航、内容同宽）。谱面按容器宽度等比
  压缩小节宽度（下限 0.72，更窄时保留横向滚动），并裁掉上下多余留白，
  三到四小节不再出现横向滚动条。

## 功能范围（MVP）

- 难度自评只决定从哪一课开始，不能直接进入视奏
- 与 L1~L3 视奏共用词汇表的识谱课：可以看键盘，弹错可重来
- 识谱课三档：L1 单手五个白键、L2 八分音符/双手/F/G 五指/平移、L3 双音与三和弦
- 识谱过关后才解锁同档视奏；L2 过关后视奏升级为双手大谱表，L3 过关后加入和弦与临时升降
- 本地算法生成原创视奏短句（消耗式题库，一条最多 2 遍）
- 智能指法提示（视奏可开关，识谱始终显示）
- MIDI 键盘实时弹奏识别
- 模拟键盘输入：没有 MIDI 键盘时用电脑键盘弹奏（设置抽屉 → 输入方式）
- 节拍器（可调速与开关）、乐谱进度条、随弹奏自动滚动与三色标注
- 练习复盘，错题本收录视奏与曲库跟弹中的错误，可回练习页重练
- 乐理练习：单音、符号、音程、和弦、临时升降、和弦进行、音型、旋律听辨；
  另有 10 组专项题组，只作为自由练习的预设，不写第二份进度
- L3 完整课：4 节单手和弦课 + L3 过关测试；L3 乐理预备课 9 节，完成记录写进本地档案
- 曲库：分段试听与跟弹，缺技能清单可直接跳到对应微课
- 练习记录：按页面停留时长累计，今日页与「我的」页显示条数、时长和连续天数

## 模拟键盘输入（无 MIDI 键盘时）

顶栏右上「设置」→「输入方式」→ 把「模拟键盘」打开，即可用电脑键盘代替 MIDI 键盘弹奏。
开启后顶栏设备状态会显示「模拟键盘」，屏幕下方琴键会标注对应键位，练习流程
（识谱 / 视奏 / 过关测试）与真实 MIDI 完全一致。

```
黑键   S D   G H J        2 3   5 6 7
白键   Z X C V B N M      Q W E R T Y U I
       C D E F G A B      C D E F G A B C
       低音区 (C3–B3)      高音区 (C4–C5)
```

键盘监听只在模拟键盘开关打开时生效；输入框内打字、按住 Ctrl/Cmd 时不会触发音符。

## 识谱课：L1 与 L2

L1 用单手五个白键把符号和拍子认熟；L2 在同一套键盘上继续加料，每一步都只加一样东西：

- **L2-1 八分音符**：一拍两个八分音，还是那五个白键。
- **L2-2 双手交替**：右手一小节、左手一小节，不同时弹。
- **L2-3 双手同拍**：两手节奏相同，或一只手拉长音、另一只手走四分/八分。
- **L2-4 F 五指 / L2-5 G 五指**：各带一个调号（F 一个降号、G 一个升号），
  先右手找对 8 个、再左手找对 8 个；谱上的黑键直接在模拟键盘/琴键图上标出。
- **L2-6 五指平移**：一条短句里从 C 位挪到 D 位一次，两条短句后进 L2 过关测试。
- **L2 过关测试**：一条新的 4 小节双手谱，含八分音符，调在 C/F/G 里抽一个，60 BPM；
  音高错不超过 2 个、明显的节奏中断不超过 1 次；同一档连续 3 次不过降 8 BPM（最低 44）。

找键课用计数推进：弹错不扣分也不回退，只记弹对的次数，所以卡住时重弹同一个键就好。

## L3 和弦课与 L3 预备课

L3 有两条并行的线，进度都只写一份 `Profile`：

- **L3 和弦识谱课（主线）**：L2 过关后解锁，4 节单手课 + L3 过关测试。
  - `L3R-1 双音`：两个音同时按下，先看清两个符头的位置。
  - `L3R-2 右手三和弦`：根音、三音、五音同时按，1/3/5 指。
  - `L3R-3 左手三和弦`：同一组音换到左手 5/3/1 指。
  - `L3R-4 临时升降`：升号、降号、还原号，以及「临时记号只管本小节」。
  - 每课两条短句；四课结束后进入 `L3R-test`：双手 4 小节，左手三和弦铺底，
    右手含三和弦与一个临时记号。音高错不超过 3 个、明显节奏中断不超过 1 次。
    连续 3 次不过降 8 BPM。过关后才解锁 L3 视奏。
- **L3 乐理预备课（补短板）**：9 节——三和弦、临时升降、双音音程、和弦连接、
  单音与谱号、符号与表情、音型走向、听调性、综合小测。完成状态写在
  `Profile.l3PrepCompleted`，技能账本只写 `learning`。它是可选的补课线，
  不阻塞 L3 和弦课；曲库缺技能清单里的「去 L3 预备 · 和弦连接」会直接打开对应一节。

过关测试与和弦评测由 `src/domain/compare.ts` 处理：同一拍上的多个音先并成一组，
只按对一个音算一次错，不会把一个三和弦拆成三个错误。L3 课的进度只由
`lessonId + linesCompleted` 记录，不再有第二份 `curriculumCompleted`。

## 曲库：分段跟弹与缺技能直达

- 每首曲子的每个编配都可以试听、看缺哪些技能；技能账本只认 `passed`，
  上完课不会直接变成「已掌握」。
- **分段**：按两小节切段，可先选「第 1–2 小节」跟弹，不用一上来就整首。
- **跟弹本段**：把当前段（按当前「双手/右手/左手」选择）切成一份独立谱子，
  直接进入视奏流程；同一段可以反复练，不消耗「一条最多 2 遍」的额度。
- 练完的复盘主按钮是「回到曲库」；错误仍会进错题本，之后可以从练习页重练。
- 缺技能清单里，L1–L3 的每一项都有「去 L1 跟拍」「去 L3 三和弦」这类直达按钮，
  跳到具体课位；L4+ 暂时没有配套微课，显示「暂无微课」。

## 练习记录与今日完成态

- 进入识谱、视奏、过关测试、乐理/预备课、曲库页面时开始计时，离开或完成时结算；
  停留不足 15 秒不记，单次最多记 45 分钟，避免页面开着过夜灌时长。
- 记录按本地日期聚合，今日页显示「今天已练过 / 今天还没开始」、条数、时长和
  连续天数；「我的」页显示今日、连续与累计的条数/时长。
- 练习记录只用于反馈，不影响任何解锁判定。

## 视奏的读谱辅助

视奏页把「准备—演奏—复盘」三段做得更看得见：

- **听一遍**：准备阶段点「听一遍」会从头播这条，同时进度条往前走、谱面上正在响的那个音用强调色跟随，页内自动滚到它的位置；播完自动收回，不留下标记。
- **小节进度**：进度条按小节画出刻度，右侧用「第 n/4 小节」标出当前位置。
- **准备倒计时**：25 秒准备有可视化进度条，并将这条还剩几遍（消耗式题库最多 2 遍）写在页面上。
- **复盘总览**：复盘页先给一行「共 4 小节 · 错音 n 处 · 节奏偏差 n 处」，再是谱面标记。不使用百分制。
- **双手视奏**：L2 过关后视奏默认双手大谱表，进度条与「第 n/4 小节」按两手同一拍点线算；「听一遍」会把两手一起播一遍。L3 过关后加入三和弦与临时升降，同一拍上的多个音会合并成一个目标。

## 非功能范围（MVP）

- 无社区、无在线曲库、无麦克风拾音识别
- 不包含流行歌曲完整弹奏功能、不做考级模块
- L4–L6 仍只有技能规则和曲目，没有配套微课；L3 已有完整和弦课与预备课
- 识谱课不使用「一条最多 2 遍」；视奏保留这条规则，曲库「跟弹本段」除外
- 不做 PDF 导出，也不做云端同步

## 开发目标

验证自学成人是否愿意先认熟一小套音和节奏，再用带指法提示的视奏短句继续练。
