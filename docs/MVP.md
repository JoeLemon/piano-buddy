# Piano Buddy MVP 产品需求文档

> **项目名称**：Piano Buddy
> **产品定位**：面向**自学成人钢琴初学者**的钢琴识谱与视奏训练 App
> **版本**：MVP v0.2
> **最后更新**：2026-10-11
> **实现进度**：本文是产品边界与需求定义，落地情况见 `docs/开发进度与待办.md`（2026-10-29：591 测试 / 曲库 2 首 4 编配 / Score 支持连音线与弱起）

---

## 1. 项目概述

### 1.1 背景

市面上主流视奏工具（Sight Reading Factory 等）存在明显短板：

- 外文界面，缺少中文引导；
- 无智能指法提示；
- 训练逻辑偏向专业学习者或琴童，专业术语多；
- 难度曲线陡峭，对自学成人不友好；
- 默认用户已经会认谱。零基础直接进入视奏，会卡在数线上。

国内综合钢琴 App（弹琴吧、虫虫等）：视奏只是附属小模块，缺少完整视奏训练体系。

**自学成人练视奏的现状痛点**：

1. 还没认熟的音，就被要求连续视奏；
2. 没人现场纠正指法；
3. 分不清「练曲子」和「视奏训练」，习惯弹错就反复回退重弹；
4. 无法自行判断节奏是否稳定；
5. 很难评估自身水平，容易选过难材料，快速挫败放弃；
6. 没有老师教「正确的视奏练习方法」。

### 1.2 MVP 目标

最小可用版本聚焦一条主线：**先识谱，再视奏**。识谱负责把符号连到键和手指上；视奏负责在已经认熟的范围内连续读新谱。

验证 4 个核心假设：

1. 零基础成人先把一小套音和节奏练到能直接认，再进入视奏，能弹完短句；
2. 自学成人愿意使用**带智能指法提示**的自动生成视奏短句进行短时间练习；
3. MIDI 键盘接入 + 演奏后描述性反馈，能帮助自学成人识别节奏、读谱问题；
4. App 内置标准化视奏训练引导，能够纠正自学用户错误的练习习惯，持续提升读谱能力。

### 1.3 非目标（明确划界，防止需求膨胀）

- ❌ 不做完整流行曲库、整首乐曲弹奏功能
- ❌ MVP 不做麦克风音频识别（声学钢琴拾音识别不稳定，放到二期）
- ❌ 不做社交、排行榜、打卡社区
- ❌ 不做音阶/琶音独立专项训练（仅在视奏片段内附带出现）
- ❌ 不支持图片乐谱 OCR 导入（二期）
- ❌ 不做完整系统乐理课程。识谱只教「这个符号在键盘上是哪里、怎么数拍」，不讲音程名称体系、大小调全貌、和弦功能
- ❌ 不开发考级专项模块（目标用户基本不参加钢琴考级）
- ❌ 识谱不使用消耗式题库，视奏不取消「一条最多两遍」

## 2. 用户画像：自学成人钢琴初学者

| 维度 | 详情 |
|---|---|
| 年龄 | 20～50 岁 |
| 学习背景 | 自学，无线下钢琴老师；乐理基础薄弱，知识碎片化，抵触大量专业术语 |
| 硬件 | 多数拥有电钢琴 / MIDI 键盘；少量原声钢琴（MVP 暂不支持麦克风拾音） |
| 练习场景 | 工作日碎片化练习；单次练习 5–10 分钟；很难抽出大块时间练琴 |
| 学习目标 | 看懂五线谱；以后拿到简易乐谱可以直接试弹；建立读谱能力，不靠死记硬背音符；享受弹琴乐趣 |
| 行为特征 | 自尊心强，讨厌低分打击；容易高估自身水平；弹错就习惯性停下来重弹；遇到指法卡点会卡住；缺乏外部反馈，分不清节奏是否稳定 |

> **两条短板要分开处理**：认音不熟，用识谱补上；没人教「怎么练视奏」、也没有指法指导，用视奏流程和指法提示补上。视奏材料不得超前于已经过关的识谱词汇。

## 3. 识谱与视奏怎么咬合

每一档都是同一套词汇的两种练法。

| | 识谱 | 视奏 |
|---|---|---|
| 目的 | 看到符号就知道按哪个键、数几拍 | 在已经会的符号里连续读一条新谱 |
| 看键盘 | 允许，页面写「可以看键盘」 | 页面写「眼睛尽量看谱」 |
| 屏幕键盘图 | 有，只标出目标键，不能点按发声 | 不显示 |
| 弹错 | 停下，改正这个音，再继续 | 做标记，不打断，不许回退 |
| 同一条 | 课内可重复；过关测试每次换新题 | 最多 2 遍，然后不再推荐 |
| 指法 | 始终显示，按该课的固定手位 | 可全局关闭，作为自测 |
| 速度 | 课内不限速；过关测试才开节拍器 | 跟节拍器，连续弹完 |
| 解锁 | 学完该档全部课，并通过该档测试 | 只有对应识谱过关后才能进入 |

手动难度只能在**已解锁**的视奏档里下调或平调。升到更高视奏档，必须先过该档识谱。自评不能直接解锁视奏。

开发按 L1 → L6 的顺序做。后一档的视奏生成器只能使用本档及更低档已经写明的词汇。

## 4. 词汇表（生成器约束）

视奏生成器不得发出该档表格之外的音、节奏、调号、拍号和记号。识谱新内容是在上一档之上追加的。

音名使用科学音高：中央 C 为 C4。

### 4.1 总表

| 档 | 识谱新教的内容 | 该档视奏允许使用 | 该档视奏仍然禁止 |
|---|---|---|---|
| **L1** | 拍子；高音谱 C4–G4；低音谱 C3–G3；四分、二分、全音符及对应休止符；4/4；左右手分开的五指位置 | 上列全部，每次只练一只手 | 八分音符、黑键、升降号、双手同时、和弦、连线 |
| **L2** | 八分音符与八分休止；双手交替和双手同拍；F、G 大调五指及一个降号、一个升号；五指整体平移一个二度 | L1 全部，外加本档新内容。双手节奏相同，或一只手保持、另一只手移动 | 附点、切分、和弦、临时升降号、3/4、两个以上升降号的调号 |
| **L3** | 单手叠置的三度、五度；C、F、G 原位三和弦；临时升、降、还原，效力到本小节结束 | L2 全部，外加本档。和弦只用四分及更长的时值 | 转位和弦、连线、附点、切分、十六分音符 |
| **L4** | 不同音上的连线；同一音上的连线（按住）；D 大调与降 B 大调五指；3/4；手位两端各扩一个二度；看下一音 | L3 全部，外加本档。乐句可以到 8 小节 | 附点、切分、十六分音符、超过两条加线、六度以上的跳进 |
| **L5** | 附点二分；附点四分加八分；八分-四分-八分；调号音的临时还原 | L4 全部，外加本档节奏 | 十六分音符、三连音、远距离跳进 |
| **L6** | 一拍四个十六分、前八后十六、前十六后八；六度与八度跳进；上下各最多两条加线 | L5 全部，外加本档。用来过渡到简易谱，仍不是整首流行曲 | 三连音、三十二分音符、摇摆节奏、4/4 与 3/4 以外的拍号、两个升降号以上的新调、小调音阶课 |

### 4.2 各档手位

手指 1 是大拇指。识谱课内指法按这张表固定，不另算「最优指法」。

| 手位 | 右手（1 → 5） | 左手（5 → 1） | 首次出现 |
|---|---|---|---|
| C 五指 | C4 D4 E4 F4 G4 | C3 D3 E3 F3 G3 | L1 |
| 平移到 D | D4 E4 F4 G4 A4 | D3 E3 F3 G3 A3 | L2 |
| F 五指 | F4 G4 A4 Bb4 C5 | F3 G3 A3 Bb3 C4 | L2 |
| G 五指 | G4 A4 B4 C5 D5 | G3 A3 B3 C4 D4 | L2 |
| D 大调五指 | D4 E4 F#4 G4 A4 | D3 E3 F#3 G3 A3 | L4 |
| 降 B 五指 | Bb4 C5 D5 Eb5 F5 | Bb3 C4 D4 Eb4 F4 | L4 |

L4 的「两端各扩一个二度」只在已经学过的手位两侧加一个音，例如 C 五指右手可以碰到 B3 或 A4。L6 的跳进落点必须落在上下各两条加线以内，并且与前一个音相距六度或八度，不生成更大的跳跃。

### 4.3 节奏型

| 档 | 可以出现的节奏 | 课上先怎么教 |
|---|---|---|
| L1 | 四分、二分、全音符；四分休止、二分休止、全休止 | 先跟拍敲，再放到五个音上。四分 = 一拍，二分 = 两拍，全音符 = 四拍 |
| L2 | 一拍里两个八分；八分休止 | 仍用已经会的音。先单手，再双手 |
| L3 | 不新增节奏。和弦落在四分或更长的音上 | 先分开弹三个音，再一起按下 |
| L4 | 不新增节奏。新增 3/4：每小节三拍 | 连线先在两个音上教 |
| L5 | 附点二分；附点四分 + 八分；八分-四分-八分 | 先用任意键敲节奏，口数「1、2、3」或「1 和」。敲稳后再放上音符 |
| L6 | 四个十六分；八分 + 两个十六分；两个十六分 + 八分 | 过关测试速度降到 48 BPM，课内不限速 |

## 5. 识谱课程

每一课只有一个新点，一次练习控制在 5 分钟内。顺序固定：一张卡片，然后找键，然后一条短句。

卡片不超过两句白话，立刻能在键盘上试。例如 L1 右手 D：「D 在中央 C 上面一个白键，高音谱第二线下面一格，右手二指。」

课内规则：

1. 屏幕键盘图标出目标键；
2. 弹错就停在这个音上，提示音名、方向和手指，不打分；
3. 认错的音在后面的题目里至少再出现 2 次；
4. 没单独写标准的课：找对 8 次，或弹完 2 条 4 小节，就进入下一课。某一课写了自己的练完标准时，以该课为准；
5. 同一知识点可以换新题再练，不设「最多两遍」。

### 5.1 L1 入门：五个音和拍子

| 课 | 内容 | 练完的标准 |
|---|---|---|
| L1-1 跟拍 | 不看谱。节拍器 60 BPM，用任意一个键敲四分音符，只判断间隔，不判断音高 | 连续跟上 8 拍 |
| L1-2 右手五个音 | 高音谱 C4–G4。中央 C 写在下加一线。手指 1–5 放在这五个键上 | 单音找对 8 次 |
| L1-3 右手节奏 | 用这五个音读四分、二分、全音符和对应休止符 | 弹完 2 条 4 小节 |
| L1-4 左手五个音 | 低音谱 C3–G3，左手 5 放在 C3 | 单音找对 8 次，再弹完 2 条 4 小节 |

### 5.2 L2 双手、八分音符、两个新调

| 课 | 内容 | 练完的标准 |
|---|---|---|
| L2-1 八分音符 | 一拍两个音，音仍是 L1 的五个音，单手 | 弹完 2 条 4 小节 |
| L2-2 双手交替 | 右手一小节，左手一小节，不同时弹 | 弹完 2 条 4 小节 |
| L2-3 双手同拍 | 两手节奏相同，或一只手拉长音、另一只手弹四分或八分 | 弹完 2 条 4 小节 |
| L2-4 F 五指 | 一个降号：遇到调号里的 B，弹黑键。先右手，再左手 | 每个手找对 8 次 |
| L2-5 G 五指 | 一个升号：遇到调号里的 F，弹黑键。先右手，再左手 | 每个手找对 8 次 |
| L2-6 五指平移 | C 大调里从 C 位置挪到 D 位置，一条里只挪一次 | 弹完 2 条 4 小节 |

### 5.3 L3 叠在一起的音，和临时升降号

| 课 | 内容 | 练完的标准 |
|---|---|---|
| L3-1 两个音 | 三度、五度。先逐个弹，再同时按下。单手 | 找对 8 组 |
| L3-2 右手和弦 | C、F、G 原位三和弦，都落在该调五指内：1、3、5 指 | 每个和弦找对 4 次 |
| L3-3 左手和弦 | 同样三个和弦 | 每个和弦找对 4 次 |
| L3-4 临时升降号 | 升：高半音；降：低半音；还原：回到白键。只管本小节 | 找对 8 次 |

课上不使用「大三和弦、主和弦、属和弦」这些名称。文案用「这三个音一起按下」。

### 5.4 L4 连线、新调、三拍子、看下一个音

| 课 | 内容 | 练完的标准 |
|---|---|---|
| L4-1 连着弹 | 弧线连着不同的音：音要连上，不要每个都断开 | 弹完 2 条 |
| L4-2 按住 | 弧线连着同一个音：第二个音不用再弹，按住直到它的拍子结束 | 找对 8 次 |
| L4-3 两个升号或降号 | D 大调五指；降 B 五指。调号里的音弹黑键 | 每个调、每只手找对 8 次 |
| L4-4 三拍子 | 3/4，每小节数三下。音用已经会的 | 弹完 2 条 4 小节 |
| L4-5 看下一个音 | 按住当前音，再用键盘弹出下一音。不要求跟速度视奏 | 连续弹对 8 个下一音 |

### 5.5 L5 附点和简单切分

| 课 | 内容 | 练完的标准 |
|---|---|---|
| L5-1 附点 | 先用任意键敲节奏，不看音高：附点二分是三拍；附点四分加八分是「长、短」 | 敲对 8 拍后，放上已会的音，弹完 2 条 |
| L5-2 切分 | 先用任意键敲节奏：八分-四分-八分 | 敲对 8 拍后，弹完 2 条 |
| L5-3 还原调号音 | 调号里本来是黑键的音，遇到还原就弹白键，只管本小节 | 找对 8 次 |

### 5.6 L6 更快的细分和离开五指位置

| 课 | 内容 | 练完的标准 |
|---|---|---|
| L6-1 十六分音符 | 四个十六分；前八后十六；前十六后八。音用已经会的 | 弹完 2 条。测试速度见 5.7 |
| L6-2 跳进 | 六度、八度。先看落点的手指，再移动整只手 | 找对 8 次 |
| L6-3 加线 | 高音谱和低音谱，向上、向下各最多两条 | 找对 8 次 |

过关文案说明：下一步视奏仍然是短句，用来接近简易谱，不是弹一整首流行曲。

### 5.7 过关测试

某档全部课练完后，做一次当场生成的新题。刚练过的那一条不能拿来当测试。每条测试至少含 8 个音，避免全是全音符时，错 2 个音就占掉一半。

| 档 | 测试内容 | 速度 | 算通过 |
|---|---|---|---|
| L1 | 右手一条新的 4 小节，再左手一条。只含 C 五指和 L1 节奏 | 60 BPM | 每条音高错不超过 2 个，并且连续弹完 |
| L2 | 一条 4 小节，含八分音符，并且双手都出现。调只在 C、F、G 中抽一个 | 60 BPM | 音高错不超过 2 个，并且连续弹完 |
| L3 | 一条 4 小节双手，至少一个原位和弦，至少一个临时升降号 | 60 BPM | 音高错不超过 3 个。和弦里错一个音算 1 个错误 |
| L4 | 一条 8 小节，含连线，并且含 3/4 或 D / 降 B 其中之一 | 52 BPM | 音高错不超过 3 个，并且连续弹完 |
| L5 | 一条 4 到 8 小节，含附点或切分其中一种 | 52 BPM | 音高错不超过 3 个。反馈先讲节奏，再讲错音 |
| L6 | 一条 4 小节，含一组十六分音符，以及一次跳进或加线 | 48 BPM | 音高错不超过 3 个，并且连续弹完 |

连续弹完的判定借用视奏的 MIDI 比对：节拍器不停。某个音比拍点晚了超过 2 拍，记一次节奏中断。一条里节奏中断达到 2 次，测试不通过。

界面不显示百分制。通过时写：「这些音可以直接认了。接下来的视奏里只会用到它们。」没通过时指出一个具体的音或节奏，例如：「F 还要找一下。它在 E 上面一格，右手四指。再来一条新的。」

同一档连续 3 次测试不通过：只把该档测试速度再降 8 BPM，音的范围不放宽。降速只发生一次，最低到 44 BPM。第 4 次起仍用降速后的标准，并继续优先练习认错的音。

左右手分开解锁只用于 L1：右手测试通过后，可以做右手视奏 L1；左手同理。L2 及以后的视奏要求左右手 L1 都已通过，并且本档测试通过。

### 5.8 第一次打开时怎么分流

保留 3 道自评，它只决定从哪里开始测试，不直接进入视奏。

| 自评 | 进入 |
|---|---|
| 不认识高音谱 | 识谱 L1-1，从跟拍和右手五个音学起 |
| 认识高音谱，不认识低音谱 | 先做 L1 右手过关测试。通过则进入 L1-4 左手；不通过则从 L1-2 学 |
| 两个谱号都认识，跟不上拍 | 识谱 L1-1 |
| 三道都选「会」 | 从 L1 完整过关测试开始 |

三道都选「会」时：某一档测试通过后，可以再试更高一档，最多连续加试 2 档。失败的那一档进入识谱第一课。已经通过的档位，视奏保持解锁。这样既不靠自评跳级，也不会一次把六档都测完。

## 6. 视奏功能（在已解锁词汇内）

### 6.1 难度与生成

算法本地生成原创视奏短句。某一档的生成参数只能从第 4 节该档词汇里取。

| 难度 | 训练目标 |
|---|---|
| **L1** | 在五个音上连续读完，建立「弹错也不停」 |
| **L2** | 双手同时读简单节奏，换 F 或 G 五指，或平移一次手位 |
| **L3** | 读到叠置的音和偶尔的临时升降号时，手还能往下走 |
| **L4** | 看在下一个音的前面；连线不断开 |
| **L5** | 附点和简单切分仍能跟上拍 |
| **L6** | 离开五指位置的短跳进，接近简易谱的密度 |

可配置参数：调号、拍号、音域、乐句长度。配置界面只能列出当前档词汇表里有的选项。L1–L3 默认 4 小节，L4–L5 可以到 8 小节，L6 默认 4 小节。

> **消耗式题库只用于视奏**：单条视奏片段最多练习 2 遍，之后不再推荐。识谱不使用这条规则。

### 6.2 智能指法推荐

- 视奏里按乐句音程和手位生成推荐指法，左右手分开标；
- L1–L3 优先用第 4.2 节的固定五指，不另做复杂指法；
- L4 起允许为平移和两端扩展更换手位；L6 的跳进再标落点手指。仍然优先顺手，不追求专业最优；
- 一键全局开关：【显示指法 / 隐藏指法（自测模式）】；
- 谱面展示：音符上方小字数字；
- 识谱课不受这个开关影响，指法始终显示。

### 6.3 节奏预览与分句练习

1. 内置节拍器。识谱过关测试使用第 5.7 节的速度。视奏默认用同一速度，用户可在 40–120 BPM 之间调整。调速度不改变本档允许的节奏型；
2. MIDI 乐谱预览播放，可单独播放右手 / 左手；
3. 自动按乐句分句，支持单句循环预览；
4. 轻量节奏预览：只看节奏，用任意键敲，或自己默读。App 只判断敲键的间隔。L5 的附点和切分必须先走这一步，再进入视奏。

### 6.4 MIDI 键盘实时弹奏识别

> MVP 仅支持蓝牙 / USB MIDI 电钢琴、MIDI 键盘。卡片可以先看。找键、敲节奏、过关测试和视奏都要已连接的 MIDI。没连接键盘时，不能把一课标成练完，也不能开始视奏。

视奏演奏规则：

1. 弹奏过程禁止中途暂停、回退重弹小节；
2. 实时高亮错音，不中断演奏，不弹出负面提示；
3. 提示文案：「眼睛尽量保持看谱，不要盯着键盘」；
4. 记录音高和触发时间，区分音高错误、节奏超前 / 滞后。

识谱找键阶段使用另一套规则：弹错停下，允许看键盘，允许重弹当前音。

### 6.5 练习复盘

优先级：**节奏问题 > 音高错误**。通俗中文，不使用百分制。

视奏复盘示例：

> 完成啦！大部分音都读对了，这两处节奏忽快忽慢，可以降低速度再试一次。

复盘内容：

1. 练习总览：小节数量、简要错误描述；
2. 谱面标记：错音、节奏偏差位置；
3. 指法对比：展示推荐指法，解释手位思路；
4. 错题乐句进入错题本，可单独再练。错题本只收视奏。识谱认错的音记在识谱进度里，用来安排后面的识谱题，不进入错题本。

### 6.6 首页引导

首页两个入口：「先认谱」「5 分钟视奏」。

视奏入口在当前档未解锁时，转入该档识谱，并说明原因，例如：「视奏里会出现八分音符，先认这一种节奏。」

视奏提示卡片：

- 不要弹错就停下来反复重弹；
- 每条新谱最多练习 2 遍；
- 视奏目标不是弹完美，是持续读谱。

识谱提示卡片：

- 可以看键盘；
- 这个阶段的目标是认准，不是连续视奏；
- 认熟之后，视奏里才会出现这些音。

### 6.7 基础设置与 PDF 导出

1. 用户设置：当前已解锁档位、每日练习目标（5min / 10min）、谱面缩放、界面主题；
2. PDF 导出视奏谱。识谱不单独增加导出。

## 7. 标准练习流程

### 7.1 识谱一课

1. 卡片：这个符号在哪、用哪根手指、占几拍。
2. 找键：弹对才进下一个。弹错则停住并提示。
3. 短句：4 小节，可以停、可以重弹当前音。节拍器可选。
4. 达到第 5 节该课的练完标准后，进入下一课。该档最后一课之后进入过关测试。

### 7.2 视奏一条

**Step 1：准备（20～30 秒，先不要弹）**

- 「先不要动手。看看调号、拍号，左右手大概在哪一块，心里数一下节奏。」
- 高亮调号和临时升降号。这些记号都应当已经在识谱里见过。
- 可选开或关指法。

**Step 2：连续演奏**

- 不可回退；
- 错音只标记，不打断；
- 提示眼睛看谱。

**Step 3：复盘**

- 区分节奏和音高；
- 展示推荐指法；
- 白话反馈。

**Step 4：收尾**

- 本条记入消耗，最多 2 次；
- 推荐下一条同档新视奏。若用户要升档，先检查下一档识谱是否过关。

## 8. 技术栈

两条可选路线，按需选择：

### 方案 A：Flutter（推荐移动端 iOS + Android）

- 前端：Flutter
- 五线谱渲染：VexFlow
- MIDI：flutter_midi 处理蓝牙 / USB MIDI 输入输出
- 存储：本地 SQLite，保存用户配置、练习记录、错题片段
- 核心计算：乐谱生成、MIDI 比对算法全部本地运行，**不需要后端服务**

### 方案 B：Web 优先（快速原型开发，后续打包桌面端）

- 前端：Vue + VexFlow 渲染五线谱
- MIDI：Web MIDI API（浏览器原生 MIDI）
- 存储：IndexedDB 本地持久化存储

> **MVP 原则**：全部本地计算，不依赖云端大模型，降低延迟、服务器成本与隐私风险。识谱与视奏共用乐谱生成和 MIDI 比对，用模式区分「弹错停下」和「弹错继续」。

## 9. 数据模型（精简）

| 数据实体 | 关键字段 |
|---|---|
| **UserProfile** | 自评答案、各档识谱状态（未学 / 学习中 / 已过关）、左右手 L1 是否分别过关、已解锁视奏档、每日练习目标、界面偏好 |
| **ReadingProgress** | 当前课、认错的音与节奏型、该档测试连续失败次数、是否已降速 |
| **ExerciseTemplate** | 模式（识谱课 / 识谱测试 / 视奏）、档位、手位、调号、拍号、小节数。可用的音和节奏以第 4 节该档表格为准 |
| **ExerciseRecord** | 模式、练习时间、演奏事件序列、错误列表 |
| **ErrorSnippet** | 仅视奏错题：乐谱片段参数、错误类型 |

生成器读取 `ExerciseTemplate` 的档位后，只能从第 4 节该档表格里选音和节奏。

## 10. UI/UX 设计原则（面向自学成人）

1. **界面极简**：中文为主，减少乐理专业术语；
2. **谱面清晰**：支持缩放；指法提示清晰柔和，不遮挡音符；
3. **反馈温和**：拒绝打击式评价，优先正向鼓励；没通过时只指出一个音或一种节奏；
4. **操作链路短**：进入当前该做的练习最多 3 步；
5. **信息轻量化**：不堆砌文字，提示用短句；
6. **两种练法长得不一样**：识谱能看见键盘图；视奏看不见。避免用户把视奏练成识谱，或在识谱里被禁止回退。

## 11. 风险清单 & 应对策略

| 风险 | 影响 | 应对 |
|---|---|---|
| MIDI 设备兼容性差异 | 部分廉价 MIDI 键盘连接异常 | MVP 限定主流 MIDI 设备；首页清晰标注设备兼容范围 |
| 乐谱生成算法产出不合理、难弹乐句 | 用户体验差 | 生成器受第 4 节词汇表约束；限制过大音程；和弦只允许列出的原位三和弦 |
| 识谱没有过关就进入视奏 | 用户回到数线，并对抗「不许回退」 | 解锁由过关测试决定，自评和手动升档都不能绕过 |
| 识谱做成乐理课 | 成人放弃 | 一课一个新点，卡片两句；不讲和弦功能和音程体系 |
| 过关太严，人被卡在某一档 | 留存差 | 不显示分数；连续 3 次失败只降速，不扩大音域；认错的音优先再出现 |
| 智能指法推荐不合理 | 核心卖点失效 | L1–L3 用固定五指表；复杂指法留到 L4 以后，并优先顺手 |
| 用户习惯难纠正（弹错就回退） | 视奏效果变差 | 这条约束只加在视奏上。识谱允许重弹，避免在认音阶段就惩罚停顿 |
| 自学成人耐心不足 | 留存差 | 一课 5 分钟以内；视奏一条默认不超过 8 小节 |
| 版权风险 | 法律风险 | 识谱和视奏全部算法生成，不加载商业乐谱和流行曲原谱 |

## 12. MVP 上线验收标准

1. 首次启动完成 3 道自评，并按第 5.8 节进入对应识谱课或过关测试；自评不能直接打开视奏；
2. L1–L6 识谱课按第 5 节的顺序可练完。课内弹错会停下并提示，屏幕有键盘图；
3. 某档识谱过关后，同档视奏解锁；未过关时视奏入口转入识谱，并说明缺哪一种符号；
4. 视奏生成结果只含第 4 节该档允许的音、节奏、调号、拍号和记号；
5. 一键生成视奏谱，指法可开关。识谱中指法始终显示；
6. 蓝牙 / USB MIDI 可连接。识谱找键阶段认音；视奏中标记错音且不打断；
7. 视奏具备节拍器、MIDI 预览、分句预览。演奏结束有复盘，区分节奏和音高；视奏错题进入错题本；
8. 视奏谱可导出 PDF。全部功能本地运行，无强制云服务。
